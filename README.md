# Guided

*"May you find what you are searching for."*

Guided is a highly customizable, data-driven guidebook framework for Minecraft. It allows you to create interactive guidebooks, discovery trees and progression-based documentation using resource packs.

## Features

### Guidebook Types

Guided provides five guidebook types, allowing you to choose how your content is presented.

| Type | Description |
|------|-------------|
| **Book** (`book`) | Traditional two-page guidebook with multiple categories. |
| **Browser** (`browser`) | Interactive discovery tree with connected entries and multiple categories. |
| **Pamphlet** (`pamphlet`) | Traditional guidebook with a single category. |
| **Network** (`network`) | Interactive discovery tree with a single category. |
| **Entry** (`entry`) | Guidebook containing a single entry. |

### Interactive Pages

Guided includes 16 built-in page types. Pages can display formatted text, lists, images, image galleries, items, entities, multiblock structures, advancements, crafting recipes and external links. Interactive previews allow players to inspect content directly inside their guidebooks.

### Discovery Trees

Entries can be connected to create discovery trees. Each entry can have multiple connections, custom backgrounds and icons. Connections can be reversed, hidden or displayed without arrows.

### Progression-based Content

Condition providers allow you to control entry visibility based on advancements, statistics and other conditions. Page providers allow you to hide or replace individual pages when their conditions are not met.

### Customization

Guidebook textures, entry backgrounds, icons, sounds and styles can be customized using resource packs. Guided also supports text formatting, internal links, localization and reading progress.

### Addon Development

Guided provides exposed Java registries for developers who want to register custom page types, condition providers, page providers, book styles and text formatting.
